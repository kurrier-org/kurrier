### Open-source communication infrastructure, under your control.

Kurrier is a modern, self-hosted workspace for **email, calendars,
contacts and storage**.

Connect the providers and infrastructure you already use while Kurrier
gives you a unified web interface built around open standards.

**[Documentation](https://www.kurrier.org/docs)** ·
**[Contributing](https://www.kurrier.org/docs/contributing)** ·
**[Website](https://www.kurrier.org)**

------------------------------------------------------------------------

## What is Kurrier?

Kurrier brings the core tools of a modern communication workspace
together without requiring you to hand control of your data to another
platform.

-   **Email** --- IMAP, SMTP, Amazon SES, SendGrid, Mailgun and Postmark
-   **Calendars** --- CalDAV with synchronization across compatible
    devices and applications
-   **Contacts** --- CardDAV address books and synchronization
-   **Storage** --- integrated WebDAV/S3-backed file storage
-   **Authentication** --- local authentication, Google and
    standards-based OIDC/SSO
-   **Management API** --- programmatic provisioning and integration
    with external systems

Kurrier is designed to work with existing infrastructure rather than
replace it. Bring your mail provider, object storage and identity
provider, and run the application on infrastructure you control.

## Built on open standards

Kurrier uses established protocols wherever possible:

`IMAP` · `SMTP` · `CalDAV` · `CardDAV` · `WebDAV` · `OIDC`

This keeps Kurrier interoperable with existing servers, providers,
desktop clients and mobile applications without locking your data into a
proprietary ecosystem.

## Self-hosted

Kurrier is designed to be deployed on your own infrastructure and
includes Docker-based deployment support.

Configuration, installation requirements, provider setup,
authentication, APIs and deployment instructions are maintained in the
documentation.
